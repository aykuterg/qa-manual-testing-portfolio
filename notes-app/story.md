\# STORY-NOTES-101 — Manage Personal Notes



\## User Story



As a logged-in user, I want to create and manage personal notes so that I can keep track of information and tasks.



\## Acceptance Criteria



1\. A logged-in user can create a note with a title and description.

2\. A newly created note appears in the notes list.

3\. A user can edit an existing note and the updated data remains after page refresh.

4\. A user can mark a note as completed and the completed state remains after page refresh.

5\. A user can delete a note and the deleted note no longer appears.

6\. Search shows notes matching the search text and hides non-matching notes.



\## Requirement Clarification



Search should match text found in either:



\- Note title

\- Note description



Case sensitivity and partial-match behavior were not specified.
