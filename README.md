\# QA Manual Testing Portfolio



This repository contains practical manual QA projects created to demonstrate real-world software testing skills.



\## Current Projects



\### Notes App — Jira Story Testing

Manual testing of a note-management feature based on acceptance criteria and a simulated Jira workflow.



\### SauceDemo — Manual QA Case Study

Functional, exploratory, state, and checkout testing of an e-commerce demo application.



\## Skills Demonstrated



\- Requirement analysis

\- Acceptance criteria testing

\- Test planning and coverage analysis

\- Positive and negative testing

\- Exploratory testing

\- Risk-based thinking

\- End-to-end testing

\- Retesting and regression concepts

\- Browser DevTools investigation

\- Cookies and Local Storage investigation

\- State and persistence testing

\- Data integrity testing

\- Evidence-based reporting

\- Test summary reporting
